### Prologue, frame and EH

S-4C..S-1. B+10 = saved D; B+14..1C = P; B+20..28 = temporary Vector3,
later the particle handle T; B+28 is reused for a translation spill;

reused for unsigned elapsed time once M is dead. B+00/04/08/0C hold saved
EDI/EBX/EBP/ESI. Calls temporarily push below B. The local layout is a
code-generation target, not a licence to fabricate stack padding.

**EH states: none.** There is no FS registration, handler address, state
variable, try map, or cleanup funclet in this hub. The temporary handle's
destructor runs on the normal path at +139. Its creation/assignment/destruction
must have nonthrowing contracts or equivalent compiler-visible behavior if

## IDENTITY

The legacy ledger name `?d_0077b3f0@@YAXXZ` is a placeholder, not a `void()` ABI.
Raw callers are 0077E690 and 00781660, both through ILT00038E15. At

spelling W3DModelDraw versus W3DScriptedModelDraw remains less certain than
