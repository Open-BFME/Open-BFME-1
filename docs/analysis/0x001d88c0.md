## 1. CONTROL FLOW

These numbered blocks partition the body into meaningful flow regions. Every call is enumerated in the call tables below. All branch destinations and individual instructions remain available in `disasm_001d88c0.txt`.

No lookup on subsequent successful initializations. Unwind state 1 clears the initialization bit on failure.
2. **+07E..+0EB, local vector and empty-input exit.** Construct V's base with allocator at S+37, erase [V.begin,V.end) even though just constructed. State becomes 5.
