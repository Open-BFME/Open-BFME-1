## Limits and next useful investigation

The primary deliverable is the complete byte partition and reusable drafts. No exact byte-match, link closure, runtime behavior, or whole-tree gate is claimed. Probe masks relocations: a matching shape would still require the real callee symbols/ABI and identity checks before add_match. Several address-derived declarations intentionally have no pins; no pin was invented to satisfy them.

Existing shared headers and ledger labels sometimes conflict with these witnesses, so no shared header was changed to make a caller fit.

The session used no git commands, full gate, whole-tree build, game launch, hand-written ledger CSV changes, MASM, inline assembly, naked functions, or emitted bytes. It stopped after bounded shape attempts and banking rather than leaving nonmatching reconstructions in Code.
