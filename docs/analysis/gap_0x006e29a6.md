## Behavior and remaining obstacle

Mode 1 lazily loads and binds textures, sets cached stage/render states, builds three texture transforms, retains a matrix and point/normal/plane, advances two wrapped texture offsets, and optionally grows another transform. Mode 2 updates a four-state fade counter, chooses one texture handle, sets sampler/stage state, updates a scrolling transform, and derives a packed grayscale render value. The only literal string used directly here is the empty fallback for a null shared-string buffer. Runtime texture names come from the config strings, so no original class identity follows from them.

The biggest obstacle is the original matrix-temporary lifetime and stack allocation, followed by x87 scheduling and local-variable/register selection. Fourteen development probes plus the delivered-source repro are recorded. Tested shapes include named matrix products, operator chains, ordinary versus forced inline multiply, an explicit copy constructor, shared versus branch-local scalars, and a native D3DXMATRIX return helper. The last helper preserves the same best bytes while avoiding a replacement matrix type. No arbitrary stack padding, byte emission, inline assembly, or executable-address calls were added.

Float details that must survive any resumed work:

- The two stores around `fsqrt` are actual float-rounding boundaries (0x006E439F and 0x006E43A9). The draft expresses them in natural C++ using volatile local floats; the existing WWMath Sqrt implementation uses inline assembly, which was not imported into the body.
- The radius qword at VA 0x0111E2C0 is **double(float(0.15f))**, not the closest double to decimal 0.15. Retail adds base + linear before the quadratic term.
- The mode-1 elapsed value rounds to float at 0x006E47A5; mode 2 retains the converted integer in ST0 across both multiplies. Remaining x87 differences are not declared equivalent.
- The texture normal's third component comes from matrix offset 0x10. The Vec3Transform output is four floats even though only xyz is retained.
