The giant initializers are redundant at runtime: every noise byte is replaced by the 2048-iteration sampling loop before use. They must nevertheless be preserved for byte matching. `noise_initializers.bin` and `.txt` are extracted **data values**, not executable-byte lifting. Their extraction checks that exactly the 1701 consecutive byte indices 0..1700 are initialized and the remaining 347 bytes are zeroed. `/Oy-` plus the aligned natural local array reproduces this entire instruction block exactly.

For each double value -32 through 31, the body computes `count = int(256 * Gaussian(sigma,0,value) + 0.5)`. Nonzero positive counts append that signed byte to the distribution; a negative count appends nothing. If fewer than 256 entries were written, the remainder is zeroed. It then draws 2048 distribution entries using `rand() & 255`. Each output row chooses another start offset `rand() & 255` into that noise buffer.

Each eight-byte chunk executes `psubusb; paddusb; psubusb; paddb`, then stores back to the same pixel address. The inner loop is do/while: it processes at least eight bytes even if width is zero or negative, and rounds a positive non-multiple-of-eight width upward. The body executes `emms` before floating-point work at 0x009BD22F and **does not execute a trailing EMMS**. The reconstruction preserves these behaviors. Caller input bounds beyond the observed call are not established; oversized widths could exceed the local noise buffer, and the bank does not add behavior-changing guards.
