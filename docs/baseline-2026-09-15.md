## What the headline means

`REBUILDS FROM WHAT WE HOLD` is `.text` provenance, not whole-exe rebuild completion. Three lanes:

- source-backed: authored C++ + vendored source + generated C++ (all compile from the tree)
- binary-input-backed: prebuilt .lib the original build also consumed (d3dx9, MSVC CRT)
- retail-only: MASM / __emit dumps of retail bytes (a boundary, not source)

The eventual 1:1 acceptance gate is a clean independent link, with no retail bytes as input, whose whole-PE SHA-256 equals `inputs/baselines/bfme1/workshop-vanilla-1.03/files/lotrbfme.exe`. No such link exists today; `build.py` verifies per-function bytes in place.
