# ?TheControlBar@@ is NOT one of those, and its entry here is masking a real
# discrepancy rather than recording a legitimate one. Five matched rows bind it to
# 0x012F33F8 (ControlBarObserverSystem, GeneralsExpPointsSystem); exactly one,
# commandButtonTooltip in ControlBar.cpp, binds it to 0x012ED7AC. That address is
# provably TheScienceStore: ScienceStore::friend_parseScienceDefinition is what

#
# So retail's commandButtonTooltip loads the science store, not the control bar,

# calls, not by treating two bases as expected.
#
# A third caller has since turned up, and it points the same way. The INI block
# registry binds the "PlayerAIType" keyword to 0x000DF1A0, whose whole body is
#   mov ecx,[0x12ed740] ; push ini ; call 0x0003EBD5

#
