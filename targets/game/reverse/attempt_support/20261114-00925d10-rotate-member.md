# 0x00925D10: single-bone normal loop as an inline Matrix3D member (20 -> 16 diffs)

Retail 0x00925D10, 1634 bytes. Measured 2026-11-14 with Wine 11 and MSVC 7.1, using the bank's `// cl:` flags. Donor reviewed: BFME 2 f6c3838e.

## Result

The best candidate is `build/wf/0x00925d10/variants/member-row-0.cpp`, with the source copied to the stash. It has **16** diffs, against 20 for the bank.

The change: the open-coded normal-rotation loop becomes a `__forceinline rotateVector3Array(in, out, count)` member of a struct derived from `Matrix3D` (`Rva00925D10Rotator`), spelled with `Row[i].X`. The `in`/`out`/`count` loop state then lives in the inline's parameters.

## Next ideas

Per-row asymmetric orders, for example row X as written and rows Y/Z as `Row[1].X*x + Row[1].Z*z + Row[1].Y*y`, applied to the member form rather than the base (the swap family was generated against the base). Also a pointer-increment `out` form, which may produce the base/index store order.
