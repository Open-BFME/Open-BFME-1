# Empty native slots 00970BC0 and 00970C00

Raw retail and Ghidra read_memory agree: each entry is C3 followed by
fifteen CC bytes. The full body is one byte, not the padded 16-byte slot.
Table VA0113E730 contains direct VA00D70BC0 at +4 (slot1), and
VA00D70C00 at +1C (slot7); the full32-byte table prefix was checked in
both sources. Matched constructor00970EC0 and destructor00970C40 both
install this table; existing address-qualified prototype siblings do not
supply a proven original class spelling.

These are table-reachable empty thiscall entries, with no explicit stack
arguments and no return-value computation. Both owner and method remain
address-qualified, rather than promoting speculative names from adjacent
loader methods. No new callee/global pins or header definitions are needed.
callees.py finds no calls at either complete extent. The two distinct
source symbols are independently byte-verified at their own addresses.
