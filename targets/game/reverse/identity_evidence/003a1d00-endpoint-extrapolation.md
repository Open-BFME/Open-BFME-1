## Experiments and stopping condition

There was no saved reconstruction at this RVA. The retry tested native returned-value arithmetic, sequential aggregate returns, mutable copies, separate endpoint scopes, the canonical `Coord3D` view, float arrays, full and selective byte copies, explicit storage of the distance, divide-form normalization from Zero Hour, an empty destructor, `/Op`, and the generated independent-store reorder. Each measured trial remains in the task folder. Native assignments and canonical field helpers produced identical output for the same scoped candidate; float-array access also reproduced the canonical candidate. The generated store reorder worsened its candidate. These results do not resolve the earlier register-allocation and x87 lifetime blocker.

The selected body is `best.cpp`, derived from `trial-004.cpp`, and is banked at `targets/game/reverse/attempts/0x003a1d00.cpp`. `probe-bank-valid.log` re-probes that exact bank. It remains nonmatching from the frame-size operand, and its constant relocation sites do not align with retail. `scoped-gate-bank.log` records the strict byte refusal and the candidate's omitted return when restricted to the retail extent. The assembly ledger remains authoritative. The bank is evidence, not a verified source recovery.

The CSV, pin-consistency, and bank class checks pass. The source-claim check refuses the unclaimed scratch translation unit; it cannot be landed as a matched source. `git-diff-check.log` flags the CRLF terminator appended by `re_log.py` to the mixed-terminator attempt log. The existing log bytes were preserved, and exactly one verdict was appended. The repository tool's output was retained without manually rewriting the log.

Reopening is justified by independently established inline point operations or temporary lifetimes that explain the frame, the early coordinate copy/load order, and the distance spill. Another untested name, allocation size, or equivalent copy spelling does not supply that evidence. An exact byte result would still require resolving the call-contract interpretation and checking the four constant references before landing.
