The 11-byte function starts after INT3 padding following the four-byte getter
at 0x005638C0. It adds 0x17C to ECX and jumps through ILT 0x00035F85 to body
0x00597F30. It ends before the next INT3 padding. This is a genuine function
boundary, unlike the nearby investigated BF6F/C226 unwind-interior claims.

The complete 109-byte callee is independently matched as Rva00597F30::init
in Rva00597F30AnimationInit.cpp. It initializes the flags and array of its
receiver, then clears two fields; it takes no source channel parameter. The
former RingRenderObjClass::Set_Outer_Scale_Channel claim instead calls a
PrimitiveAnimationChannelClass<Vector2> assignment and fails relocation
verification. No assignment pin is added to the initializer.

The address-qualified owner preserves the unknown original class identity and
its member offset. Calling that existing initializer from real C++ emits the
same 11 bytes. Full scoped verification checks the tail target. The extent is
unchanged and there is no new ledger coverage.
