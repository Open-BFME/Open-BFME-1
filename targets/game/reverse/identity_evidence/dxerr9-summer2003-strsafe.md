## StringCopyWorkerW

`?StringCopyWorkerW@@YGJPAGIPBG@Z`, RVA00AD5401,66B. The archive's entire66-byte executable section equals retail with no relocations. Entry is an EBP prologue; the final instruction is `ret0xC`, followed by the next independent section/function. Decoration, canonical SDK declaration and decoded argument accesses agree on `long __stdcall(wchar_t*, unsigned int, const wchar_t*)`; HRESULT/size_t are32-bit and wchar_t is unsigned short under the unchanged MSVC13.10 flags.

The count is an unsigned count of two-byte characters, not bytes. Zero capacity returns HRESULT80070057 without dereferencing either pointer. Otherwise a forward loop copies nonzero code units while decrementing capacity. Exhaustion backs the destination up one code unit and returns8007007A; both successful and truncating nonzero-capacity paths terminate the buffer. It deliberately adds no null-pointer fallback, overlap policy or capacity clamp absent from the native worker. No allocation, CRT, import, EH, GS, literal or table dependency exists in this66-byte leaf.

The new source preserves the already admitted lookup family's `/O1 /G6 /MT /DNDEBUG` flags and standard `<stddef.h>` definition of wchar_t. A fresh private compile reproduces all66 bytes exactly, with the original decorated ABI and zero relocation sites. Normal admission/gate is required separately; no discovery-only comparison is treated as admission. No code in this recovery is executed, especially Trace/API/debug/MessageBox callbacks.

The original archive separately names and bounds `StringCchCopyA` at00AFD193/23B, `StringCchCopyW` at00AFD1AA/23B, `StringCchPrintfA` at00AFD1C1/39B and `StringCchPrintfW` at00AFD1E8/39B. Complete adjacent executable sections, native prologues/epilogues and full relocation bindings were checked, not just a matching instruction prefix. The copy wrappers are stdcall long(destination, unsigned32 character-capacity, const source), with `ret0xC` on the error path and a tail jump to the corresponding worker otherwise. The formatting wrappers are **cdecl variadic**, with plain `ret`; standard32-bit va_start points immediately beyond the format argument and the fixed four-argument worker cleans its own16-byte stack arguments.

No invented count clamp, null-pointer fallback, allocation, GS/EH, conversion or A/W string reinterpretation is introduced. Source uses only standard stddef/stdarg headers and actual primitive declarations.
