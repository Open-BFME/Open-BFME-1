# Retail data providers at VA 0x012C4998 and 0x01075350

The digest and zero-comparison sources already have exact retail code and
address bindings, but their data symbols had no linked definition. These
definitions preserve the existing declarations' storage and initialization.

## Digest digit pointer

`Y4CommDigest.c` reads `_g_Rva012C4998HexDigits` as a pointer and indexes it
with a nibble (0 through 15). Retail writable `.data` at VA 0x012C4998
contains VA 0x012C4984. That target contains the 17 writable bytes
`0123456789abcdef` and a terminating zero. The next named pointer-cell
neighbor starts four bytes later, at VA 0x012C499C.

The source defines a private writable 17-byte array and the public writable
pointer. Its compiled ordinary `.data` section contains the array at offset
zero, three padding bytes, and the pointer at offset 20. The pointer's
DIR32 relocation targets the private array in the same section. Retail has
the same 20-byte displacement. An explicit `RetailTruth.verdict` check of
that ordinary data section returns `retail`; the pointer's existing address
binding is sufficient, with no new pin for the private array.

## Read-only zero

`Rva005BDBC0IsZero2D.cpp` defines the existing external const `Real`
`BfmeZeroRange` as `0.0f`, retaining decoration `?BfmeZeroRange@@3MB`.
Retail VA 0x01075350 is four zero bytes in `.rdata`; the following four
bytes have a distinct address name and value. The compiled definition is
exactly four bytes in `.rdata`, without relocations. An explicit
`RetailTruth.verdict` check returns `retail`.

The existing address table has other names for this immutable scalar. A
source-use review found scalar float/Real declarations, no arrays or direct
writes, and two address-taking uses that read through `volatile const
float *`. This change supplies only the established const decoration;
`BfmeZeroRange` remains a project alias, without claiming a retail owner.

Both providers' matched functions retain their instruction bytes and DIR32
references. Ordinary strong data definitions are not automatically checked
by the census's COMDAT verdict loop, so the explicit initializer checks are
required in addition to the normal source and native-link gates.
