# Credits parser and global at VA 0x012F1260

The four-byte .data cell at VA 0x012F1260 is initially null. The credits menu callbacks at retail RVAs 0x004C6AF0, 0x004C6B70 and 0x004C6C60 use it to reset, draw, delete and allocate the credits manager. The initializer uses the string CreditsMenu.wnd:ParentCreditsWindow. The paired Apt credits entry and exit bodies also replace, load, initialize, reset and delete this same pointer. The Zero Hour reference declares CreditsManager *TheCredits in `inputs/reference/CnC_Generals_Zero_Hour/GeneralsMD/Code/GameEngine/Include/GameClient/Credits.h:165` and defines it in `Source/GameClient/Credits.cpp:69` relative to that GameEngine directory.

The 25-byte body at RVA 0x0040BFC0 loads this cell, checks for null, then hands its value and the field-parse table at VA 0x010F0B78 to the INI parsing routine. Reading the table's bytes and string pointers gives ScrollRate at offset 0x14, ScrollRateEveryFrames at 0x18, ScrollDown at 0x1C, TitleColor at 0x20, MinorTitleColor at 0x24, NormalColor at 0x28, Style at 0x2C, Blank and Text, followed by a zero entry. These fields and the credits callbacks support INI::parseCredits, rather than the competing INI::parseChallengeModeDefinition identity. Both identities currently have matched functions.csv rows on this one extent. The receiver contract is static INI member code with one INI pointer argument on the stack; the global value is the parser instance argument, not the INI receiver. The retail body and its extent must remain unchanged.

Raw evidence is retained in `build/rlink/pointer-globals-1791178372/012F1260-retail.log`, `012F1260-contracts.log`, `012F1260-game-uses.log` and `credits-field-table.log` in that same folder. The attempted sanctioned identity correction was refused because --replace-rva matched two rows; `credits-identity-refusal.log` contains the refusal. No source or ledger row for this address was changed. A credits callback loading a different cell, a table at VA 0x010F0B78 describing challenge-mode fields instead of credits fields, or a different retail parser boundary would refute the proposed correction. The ledger must retire the competing parser claim before a unified data definition can pass the source identity gate.
