The successful hypothesis was that an ordinary returned pair is converted to a pair with a const key. Retail copies the converted pair's string and destroys both pair temporaries before appending parsedText to the global list. Calling an external declaration for the aggregate helper prevented the compiler from sharing the dead key slot with the ignored insertion result. The native `_STL::make_pair(factionKey, payload)` expression both retains the conversion and gives the compiler the visibility needed to share that slot.
