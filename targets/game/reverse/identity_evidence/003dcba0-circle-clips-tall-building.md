## Experiments and falsification

The saved body reproduces 383 emitted bytes against 373, with 234 non-relocation byte differences starting at `+0x5A`. Reusing the repaired query return contract, canonical Object layout, and exact radial-helper source gives 383 bytes with 226 differences. Making the complete filter constructor visible does not change that caller. Eight mechanical EH combinations produce that same result. Passing filter temporaries directly to the query reuses each constructor's returned EAX and gives 375 bytes with 81 differences; its remaining structural divergence is an extra source-pointer copy at `+0x115`. Default construction followed by assignment produces the same 375-byte body. Aggregate initialization of the three output-coordinate fields removes that copy and matches all 373 bytes. The final source-path probe also matches the target and helper independently. The full filter constructor independently matches 102 bytes.

The hypothesis is refuted by a different decoded extent, an outgoing branch omitted from these extents, any caller proving a different stack representation, a filter constructor retaining either mask reference, a radial-helper register or cleanup disagreement, an emitted unwind action that owns additional resources, or a strict relocation-aware byte gate failure. Masked equality alone is not the acceptance check.
