# RVA 0x00846B40: opaque narrow stream-iterator copy wrapper

Retail INT3 padding precedes 0x00846B40; RET at +0x2C ends a 45-byte
body, followed by INT3. Its only direct call, at RVA 0x00846B61, resolves
to RVA 0x008460D0, not the canonical template copy at 0x00835590.

`tools/callees.py 0x00846B40 45` prints the existing address identity
`?dup_008460d0@@YAXXZ` and its native object symbol. That matched row
already owns the 114-byte callee in `game/stlport/NumFacetsInstantiations.cpp`:

```cpp
_STL::ostreambuf_iterator<char> __copy<const char *,
    _STL::ostreambuf_iterator<char>, int>(
    const char *, const char *, _STL::ostreambuf_iterator<char>,
    const _STL::random_access_iterator_tag &, int *);
```

Independent retail decoding confirms the ABI rather than relying on the
opaque no-argument ledger spelling. The callee subtracts last-first,
uses the incoming iterator's streambuf pointer and success byte, appends
characters through the streambuf put area or virtual overflow, writes two
words to the hidden return buffer, returns that buffer, and ends with
plain RET at +0x71 followed by INT3. These operations agree with native
STLport `_algobase.h` and `_ostreambuf_iterator.h`. The incoming arguments
occupy seven cdecl slots: hidden result, first, last, two-word iterator,
category reference, and distance-type pointer.

The wrapper passes exactly those seven slots and cleans 28 bytes. Native
return-by-value forwards its own hidden result buffer and lets VC7.1
reuse the incoming result-pointer home for the empty iterator-category
temporary. Its complete 45-byte probe is exact.

## Binding repair

The canonical `__copy` decorated name resolves to 0x00835590. Reusing it
would hide the wrong retail call. One new address-specific declaration and
pin, `Rva008460D0` with the existing native ABI above, instead bind this
call to 0x008460D0. This adds no second ledger body or semantic identity;
the existing address-owned duplicate and source stay unchanged. The source
contains no `/alternatename` or fallback target. A cast of the opaque
no-argument declaration was tested but created a 60-byte return temporary,
so the direct typed ABI declaration is necessary for this compiler.

The wrapper itself retains `Rva00846B40`: the forwarding shape is shared
by several STLport templates and does not establish its exact original
name. The scoped gate verifies this body together with the two already
landed neighboring wrappers and validates the new direct-call pin.
