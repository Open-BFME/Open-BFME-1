# Sample-start reference layout

The assigned body occupies RVA 0x006B3E30 through 0x006B3F3E. Its two return paths use RET 4 and return a boolean in AL. The owner remains Rva006B3E30Owner. The Open BFME 2 playSample donor at game.dat RVA 0x0005E1BF is structural evidence; its MilesAudioManager identity does not rename the BFME 1 owner.

The playing reference is one pointer. The target reads its sample at +8, event reference at +0x14, file reference at +0x18, and four status bytes at +0x39 through +0x3C. The event reference leads to an info pointer at +8, event kind at +0x28 and started byte at +0x48. The file reference's data pointer is at +0x2C. Addressing the reference subobject and using its inline accessor reproduces the otherwise missing ADD followed by pointer load. The info contains two compared range words at +0x8C and +0x90; the port uses an opaque nested range view and makes no claim about its element type or STL ownership.

The landed initFilters declaration at RVA 0x006B1B40 and dispatch declaration at RVA 0x006A8210 replace the bank's linker aliases. Dispatch receives the address of the event's info reference as a four-byte value and its four-byte kind. The complete 184-byte file-name consumer at RVA 0x006B15A0 reads the string buffer and emptiness fields. Its pointer argument is passed through the existing address-derived ILT binding. The DLL import table independently identifies every sample import and its stdcall argument width.

The saved source emits 270 bytes with four differing non-relocation bytes at offsets +0xB6, +0xBD, +0xC4 and +0xCB. Retail's first three flag branches reach the stop block at +0xCC, and its last branch reaches resume at +0xD8 when clear. The compiler emits the opposite block order. Consequently the two stop/resume import references also occupy opposite sites. The relocation-masked score is diagnostic and does not certify those import bindings. The strict gate fails and restores the dump row.

Flat donor access produced 264 bytes with 174 differences. Reference wrappers produced 268 bytes with 167 differences. The nested range view recovered every register and member-load instruction. Condition inversion, an inline paused accessor, explicit labels and the finite generated return-constant variants did not change the remaining branch layout. Reopening needs evidence for the native paused-helper source or another justified branch-layout lever. Raw trials, unedited probes and the strict failed gate remain under build/donor-r7.
