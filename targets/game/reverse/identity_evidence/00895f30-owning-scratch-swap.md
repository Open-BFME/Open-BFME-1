## Retry and reproducibility

The new hypothesis was that the bank omitted the null assignment and hid throwing C++ ownership operations behind an `extern "C"` copy declaration. It would be refuted if visible ownership and the missing assignment failed to emit retail's array iterator and two unwind states. The existing bank already emits the generic array constructor iterator, contrary to its attempt narrative, but emits no EH registration frame. At the verified extent its measured output has 185 bytes, 149 overlapping non-relocation differences beginning at +0 and 119 missing bytes. That is a screening comparison, not an ABI acceptance result.

The owning temporary produced 290 bytes. Correct integer fields and member-based end pointers produced 300 bytes. Reversing the first two swap stores reproduced the first 65 bytes; moving the other inline-address definition reproduced the first 102 bytes. A visible canonical decrement helper reproduced the inline release block. Testing `otherWasInline` before `thisWasInline` then produced all 304 bytes exactly outside relocations. Replacing the two capacity branches with conditional expressions regressed to 298 bytes. The generated EH search exhausted eight combinations; disabling EH produced 235 bytes and did not fix the target. No register-only experiment was repeated unchanged.
