# Calendar helper and native receiver transport

The Open BFME 2 donor Code/Libraries/Source/Apt/AptDate.cpp at game.dat 0x006F4120 is the corresponding days-per-month algorithm. Its default-case assertion and breakpoint do not exist in BFME 1 and are omitted. The BFME 1 name stays daysInMonth from the preferred bank, with an address-derived owner. The original class name remains unknown. No donor assembly is copied.

The complete native executable body has three return instructions, all ret 8. It reads month at entry ESP+4 and year at ESP+8 and returns a full-width integer. The upper-bound branch returns 31 and all switch targets are within the executable extent. The final return ends at +0x42, establishing 66 executable bytes. Two alignment bytes follow. Three DWORD targets at +0x44 point to +0x1C, +0x24 and +0x3A. The twelve byte indices at +0x50 are 0 1 0 2 0 2 0 0 2 0 2 0. The complete contribution is 92 bytes, followed by INT3. The raw data check is retained separately; treating the index bytes as instructions explains probe linear-boundary warnings.

The complete 207-byte caller at 0x008B65E0 supplies month and year in that order at two instruction-aligned calls and leaves incoming ECX unchanged. The complete 65-byte leap helper at 0x008B64E0 reads its signed year from ESP+4, overwrites incoming ECX before using it, returns a boolean in AL on both return paths and ends ret 4. Thus the call is physically compatible with a member-call view having an ignored receiver, while its canonical existing object symbol is the stdcall isLeapYear. The new pin names that existing object symbol rather than inventing a member identity.

The stdcall preferred bank and donor scalar expression each emit 92 bytes with six register-operand differences. The donor member-call structure preserves ECX and emits exact 92 bytes outside six relocation fields. A checked single-inheritance member-pointer transport to the canonical stdcall function produces the identical direct REL32 call with no receiver adjustment or extra instruction. A compile-time array bound checks the two pointer representation widths. No indirect call remains in the emitted body. This transport is justified by the decoded ignored-ECX and identical stack contract, not by a donor class name.

The final source passes the strict scoped gate with the canonical leap predicate pin and both switch tables resolved. It has no exception frame, owned object or hidden return storage.
