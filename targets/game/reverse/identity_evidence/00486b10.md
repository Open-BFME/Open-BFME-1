# `createGadget` at 0x00486B10: four arguments, cdecl

* **Callers.** Both retail call sites reach the body through ILT 0x0003107F and
  push four arguments, then pop them with `add esp,0x10`: createWindow
  (0x004874A0) at 0x00487543 pushes 0, the window record (EBX), the gadget data
  and the type string; Rva004879A0 at 0x00487ADD pushes the source window, the
  record, the data and the type.
* **Body.** Every exit (0x00486D90, 0x00486E1C, 0x00486F6F, 0x004872B6) is a
  plain `ret`. After the SEH frame, `sub esp,0x44` and four register pushes the
  depth is 0x60, and with later pushes counted every argument access resolves to
  entry offsets 4, 8, 0xC or 0x10; none reaches a fifth argument.
* **Roles.** The type string is compared against "PUSHBUTTON" and the other
  gadget names; the data pointer is written through; the record's +0x30 field is
  the WinInstanceData whose style gains bit 1 on the PUSHBUTTON arm; the fourth
  argument is a window pointer that createWindow passes as null.
* The previous row kept Zero Hour's nine-argument list,
