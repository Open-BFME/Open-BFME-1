## Experiments and refutation

The new hypothesis was that the missing rebases and nested-buffer reload shortened live ranges and changed the frame, rather than an immutable register-allocation choice. It would be refuted if the complete indexed traversal retained the old prologue or failed to improve the saved body's measurement. The saved body emitted 532 bytes with 373 differing bytes and fifteen missing extent bytes against 547. The complete indexed trial emitted 588 bytes with 384 differing bytes and matched the register prologue. Ordering the cases as one, eight, three, two then emitted 576 bytes with only 29 differing bytes, all in the cleanup tail. Using the decoded delete expression emitted 580 bytes matching both the 547 code bytes and every alignment/table byte. Removing redundant casts and joining call lines retained that result.

Raw decoded extents, checked callee inventories, immutable trial sources, full probe output and generated shape-search output are retained in `build/008d3610-retry/`. A counterexample is any out-of-range branch or table entry, a caller with different argument provenance or cleanup, a cleanup path using a different receiver or deallocation cell, or a failure of the source gate to resolve these calls to the witnessed addresses. Byte equality alone does not establish an EA owner identity, which remains unclaimed.
