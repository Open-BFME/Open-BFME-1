## Types and ownership

The receiver preserves the caller's member names and offsets. The main image buffer and its size are at `+0x10` and `+0x14`; the auxiliary image buffer and size are at `+0x1C` and `+0x20`. Texture storage is at `+0x08`, unsigned width and height at `+0x24` and `+0x28`, mip count at `+0x34`, and format at `+0x3C`. The complete caller loads both buffer sizes, releases both buffers through delete[], and subsequently reads the created texture's format and mip count. No STL container or constructor unwind cleanup is involved in this target.

The main texture is created with format 21 and managed pool 1. The auxiliary texture requests format 28 and system-memory pool 2. Its returned format is checked for 28, 50, or 21. The first two formats supply byte zero with stride one; format 21 supplies byte three with stride four. Every destination pixel receives that byte at offset three and advances by four bytes. Both row pointers advance by their own signed pitches. Both loop bounds reload the receiver's unsigned dimensions, preserving possible aliasing by byte writes.

The lock output is the native eight-byte D3DLOCKED_RECT: signed Pitch at offset zero and pBits at offset four. The description occupies 32 bytes and exposes Format at offset zero. The preferred source uses the native format and pool enum names, DWORD widths for flags, and IDirect3DBaseTexture9 for D3DXFilterTexture. Unused interface slots and unused description fields are minimal layout views.

On success, the auxiliary texture unlocks before the main texture; then the auxiliary texture and surface release, filtering runs, and the method returns whether the main texture is non-null. Failed auxiliary locking still unlocks the main texture. Failed main locking releases both temporary interfaces. An unsupported auxiliary format releases both temporary interfaces without unlocking. Failed image loading or auxiliary creation releases the surface. Any unsuccessful overall path releases and clears the main texture. Initial main-texture creation failure clears it and returns false directly. The GetLevelDesc and filter HRESULTs are ignored in retail and in the reconstruction. No RAII cleanup was introduced into a body with no EH frame.
