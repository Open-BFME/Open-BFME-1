## Types and unwind cleanup

Complete constructors and destructors for the actual narrow string, wide string, `PeerRequest`, `PeerResponse` and `StringBase<char>` targets were decoded, including all return paths. The `StringBase<char>` copy helper copies its sole pointer and increments the pointed-to reference count. Its release helper decrements that count, frees at zero and clears the object pointer. These establish the one-dword shared ownership used by `gameName`, `tmp` and `hostName`.

The actual wide assignment helper reads the source's begin and end fields, checks self-assignment, passes that range to `0x004F3A20` and returns the destination receiver with `ret 4`. Its dispatch helper copies 16-bit values with two-byte pointer increments, updates the destination end field and calls the complete wide append helper when capacity is insufficient. The append helper reads begin, end and capacity, copies and terminates 16-bit data, releases old storage and writes all three destination fields. The wide range constructors also write all three fields and a 16-bit null terminator. This evidence establishes the payload width and ownership independently of the generated helper's name or allocation size.
