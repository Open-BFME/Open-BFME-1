# RVA 0x002C1480 passenger release

The recovery keeps the opaque `Rva002C1480Owner::method` identity. The GiantBird source cluster and its update caller locate the owner, but neither proves the original method name. No new symbol pin or STLport ledger identity is needed.

## Retry hypothesis

The landed locomotor update at RVA 0x002C12E0 witnesses the owner object pointer at +8 and the locomotor at +0x1CC. The current Object and Thing headers independently provide the contained-object, physics, ID, transform and model-condition offsets. These declarations address the earlier owner-layout blocker. The hypothesis would fail if the complete retail caller used a different receiver adjustment, if the actual containment helpers used a different payload, or if a complete reconstruction using these contracts failed to improve on the earlier recorded shape. The experiments and their original output are retained under `build/rva002c1480/`.

## Boundary and receiver

The complete target spans RVA 0x002C1480 through 0x002C16A7 inclusive. Its three returns are at 0x002C1575, 0x002C1696 and 0x002C16A7. All conditional destinations remain inside this extent, and there is no external tail jump. INT3 padding starts at 0x002C16A8. The complete caller code spans 0x002C1D80 through 0x002C213B, including both switch arms beyond its common epilogue. Its indirect switch tables follow the code. At 0x002C1E07 it forms `this - 0x10`, passes that value in ECX and calls ILT 0x0003371C at 0x002C1E0C. That thunk jumps to this target. No stack argument is supplied, and no return value is consumed. The target reads that receiver before any call and returns without argument cleanup. The ABI is a non-static thiscall method with no explicit arguments and a discarded result, represented as void.

## Container payload and indirect calls

The pointer at Object+0x1FC is a containment interface. OpenContain constructor 0x002277A0 installs the interface table at VA 0x010AC038; the independently landed CaveContain constructor installs VA 0x010AAD80. Both tables put count and item-list access at +0x100 and +0x104, and removal at +0x90. The OpenContain list getter routes through ILT 0x00027AF2 to the complete four-byte body 0x0021B850, which returns receiver+0x18. The insertion slot at +0x8C routes through ILT 0x00034955 to the complete body 0x00226790. Its value construction at 0x0022679E through 0x002267AC copies exactly one incoming pointer into node+8. It writes next and previous links separately at node+0 and node+4, reads the pointed object's template at +4, and writes no second payload field. This is pointer payload evidence from the actual constructor, rather than an inference from node allocation size. The target independently reads node+8 as an Object pointer, compares its ID at +0x74, and passes it to Thing, PhysicsBehavior and Object methods.

The OpenContain count body at 0x002225E0 has two complete RET4 paths. A nonzero incoming argument is used as the receiver of the filter helper reached through ILT 0x0001DA34, whose complete body 0x003A04A0 accepts `(Object *, Player *)` and returns a byte Boolean. The null argument returns the cached count. CaveContain's count override at 0x002198B0 tail-jumps through 0x00036165 to the complete TunnelTracker count body at 0x000F8810, which uses the same argument as a filter receiver. Therefore the target's zero argument is a null filter pointer, not a Boolean. The source preserves the target's unsigned count comparison with an explicit cast. The filter's established `Rva2225E0Filter` name is retained.

The removal slot resolves in OpenContain to 0x00227B60. Its complete body forwards the incoming `(Object *, bool)` arguments after a receiver adjustment of -0x20 to 0x00226800 through ILT 0x00014F51. The complete forwarded body reads the exposure argument as a byte and returns with RET8. This supports the two arguments in their observed order. The CaveContain override at 0x00219C70 also returns with RET8. The target calls the existing interface pointer without another adjustment.

The pointer at owner+0x30 receives a virtual call at +0x38. The machine constructed by the landed factory at 0x002C1260 installs table VA 0x010C7AD8 in constructor 0x002BFB00. Slot +0x38 follows 0x0001710C, 0x0016AD80 and 0x00027B42 to the complete goal-object setter at 0x000A0C40. Its nonnull path reads Object+0x74 and the three position fields at +0x38 through +0x40; its null path clears the goal ID, and both return with RET4. The argument is `const Object *`, and the target clears it with null. This call is represented as `setGoalObject`, retaining the opaque machine view instead of claiming a different StateMachine layout. The constructor is used to witness its installed table, not to claim constructor cleanup or ownership recovery.

## Direct callee contracts and layout

The complete Thing height accessor at 0x00131B00 returns a float in ST0 and takes no stack argument. The target calls it twice on its positive-height path. Matrix3D::Get_Z_Rotation at 0x008D68A0 reads two float fields, computes FPATAN and returns ST0. Its receiver is the owner's Object transform at +8. Thing::setOrientation at 0x00132E40 consumes one float stack slot and returns with RET4. Thing::getUnitDirectionVector3D at 0x00132970 consumes one output reference, writes all three float fields at +0, +4 and +8, and returns with RET4. PhysicsBehavior::applyMotiveForce at 0x0029AC40 consumes a pointer to three floats and has two RET4 paths; its input reads cover all three components. PhysicsBehavior::rva0029A6A0 at 0x0029A6A0 consumes a byte Boolean and returns with RET4. The target obtains PhysicsBehavior from the shared Object+0x208 field.

FXList::doFXObj at 0x00065DE0 is the existing cdecl wrapper. The target pushes the secondary Object, primary Object and FXList pointer, then cleans three stack slots. The inherited BFMEReportDamageSource::report pin reaches the complete body at 0x001C9490; it reads its first argument as an Object pointer, checks its second argument as a word-sized mode, and returns with RET8. Its receiver is the owner's Object. The notifier at 0x001BE1C0 has a RET path and a tail call through 0x0003611A on Object+0x204; the complete routed body confirms a no-stack-argument notification. Object::clearStatus at 0x00162CD0 reads one word-sized status index and returns with RET4. The model-condition update addresses the shared forty-byte mask at +0x110, using its third word and first byte of that word, rather than declaring an unrelated field at +0x118.

The target has no exception registration or owned local object with a destructor. Its locals are floats, pointer iterators and two non-owning Coord3D aggregates. The native coordinate scale expression writes all three direction fields before the force record copies X and Y and sets Z. The canonical Coord3D header is included; the inline scale helper reproduces the upstream Coord3D::scale operations without redefining the shared type. Object, Thing, Matrix3D and FXList use existing shared headers. The remaining owner, data and dispatch views keep address tokens and describe only observed fields and slots.

## Experiments and acceptance

Raw probes use the independently decoded target extent explicitly. Trials `000` and `001` used direct and bitset condition tests. Trial `002` corrected the height comparison and narrowed the shifted flags to a byte. Trial `003` tested nested guards and reproduced the preceding shape. Trial `004` separated the passenger search from the release, and trial `005` tested a postfix iterator increment. Trial `006` used a separate prefix increment. Trial `007` commuted the Y product without changing the remaining mismatch. Trial `008` replaced the hand-expanded scale with the native inline scale shape and reached byte equality. Trial `009` corrected the filter and goal-pointer declarations while retaining equality. Trial `010` records a failed source-preparation invocation; trial `011` records the native-header placement-new conflict. Trial `012` uses the already-included standard placement operators and shared headers and reaches equality. Trial `013` recompiles the source at its final game path and reaches equality. Only the scoped relocation-aware gate, recorded separately, can establish accepted byte equality.

The final relocation-aware gate passes for the complete body, its calls and all referenced constants. Its raw output is `build/rva002c1480/scoped-gate-python.log`; the landing tool's independent gate is `build/rva002c1480/add-match.log`. The declaration, class, name and pin checks pass. The ordinary CSV check reports only that the new source is untracked. The read-only Git index requires coordinator staging before that check can pass.

The complete disassembly and checked-callee output are `build/rva002c1480/retail-complete-evidence.log` and `build/rva002c1480/checked-all.log`. The vtable inventories and intermediate disassemblies remain alongside the trial sources. Refutation requires a contradictory decoded caller receiver, a different construction payload in the cited insertion slot, a differing routed ABI, or failure of the final source's relocation-aware gate. An original GiantBird method name remains unproven and is not claimed.
