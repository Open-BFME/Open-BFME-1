# Bank identifiers at 0x001649B0 (AIPlayer::isAGoodIdeaToBuildTeam)

Slot 25 of the AIPlayer vtable 0x010968B0 reaches this body through ILT
0x000320EC. The AISkirmishPlayer vtable 0x01096FB0 slot 25 reaches a different
body, 0x00168AE0. The earlier bank therefore named the wrong class
(AISkirmishPlayer); the rewritten bank declares AIPlayer::isAGoodIdeaToBuildTeam.

`quickTeamCheck` in the old bank was a file-static helper name nobody proved:
retail calls a member at 0x00164750 whose identity is still unknown. The new
bank declares it under the address-derived member name `rva00164750Check`
(AGENTS.md: an identity that cannot be proved keeps the address token). The
`isAGoodIdeaToBuildTeam` token pairs the tool reports are the same class move,
not a loss of the method name, which the new bank keeps on AIPlayer.
