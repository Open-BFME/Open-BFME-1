## Identity and extent

The complete 60-byte CrushDie constructor at RVA 0x00254B90 installs table VA 0x010B2BB8 at full-object offset 0x10. That table contains ILT VA 0x00435A08 followed by zero; the decoded thunk jumps directly to RVA 0x00254CF0. The primary table VA 0x010B2C84 has slot 2 pointing through ILT VA 0x0043F2FB to RVA 0x00254BE0, whose complete six-byte getter returns the literal `CrushDie` at VA 0x010908A8. The independently named FXListDie constructor installs its one-slot onDie table at the same subobject offset. The native DieModuleInterface declaration has exactly one method, `onDie(const DamageInfo *)`.

The callback ends with `ret 4` at +0x1E3, followed by INT3 at +0x1E6. Every ordinary branch stays inside its 486-byte extent and reaches the common epilogue. ECX is the die-interface receiver at full-object offset 0x10; the module-data pointer is read at receiver minus 0x0C and the Object pointer at receiver minus 8. The incoming DamageInfo pointer occupies one stack slot. The owner identity would be refuted by a different literal owner, a different constructor table placement, or a thunk route to another body.

## Compiler experiment and unwind check

The retry hypothesis was that the current landed audio and DieMuxData declarations could resolve the bank's layout and ABI blocker. The unchanged bank reproduced its recorded 482-byte result with 321 differing non-relocation bytes, a 0xC4 frame versus retail's 0xC0, and first difference at +0x17. Canonical AsciiString with its authentic visible isEmpty definition leaves that baseline unchanged. The EH mode generator found no improvement.

The native bitset base constructor resets its words with memset, as `inputs/vendor/stlport/stl/_bitset.h` shows. Restoring that operation, the donor's boolean-to-integer set arguments, and a directly consumed mask-constructor temporary removes the extra frame word. With the old audio adapter the result is 486 bytes but still differs at 202 non-relocation bytes, first at +0x51. Replacing the adapter with the verified ordinary virtual audio call produces all 486 bytes exactly outside relocation slots. The result survives canonical Coord3D, AsciiString, Thing and Object headers, the native one-slot die interface, and the independently proven CrushDie name.

Retail has one unwind state. State 0 destroys the local AudioEventRTS through ILT RVA 0x00026F35 to RVA 0x000B31F0, using receiver EBP minus 0xA4, then transitions to -1. The source starts that lifetime after copy construction, resets the state before normal destruction, and ends the sound's nested scope before the flag update. The compiled cleanup and FuncInfo are retained and checked against those facts; ordinary-body equality alone is insufficient.

These are metadata identity corrections to a different target, outside this callback assignment. No duplicate pin, nonvirtual replacement declaration, linker alias, or baseline exemption was used.
