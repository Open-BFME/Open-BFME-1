# RVA 0x005CC6C0 update recovery

The source retains the address-qualified owner `Rva005CC6C0Particle`. The matched caller at RVA 0x005CCA10 walks particles through their +0x3C links, places the current particle in ECX, calls ILT 0x00018F43 without stack arguments, and tests AL. That thunk jumps directly to 0x005CC6C0. This proves the no-argument receiver convention and boolean use without claiming an independently named owner.

The complete 324-byte target has returns at 0x005CC7F2 and 0x005CC803. Every conditional destination is inside its extent. There is no outgoing tail jump or EH frame. The six bytes preceding its entry and the bytes following 0x005CC804 are INT3 padding. The earlier 249-byte angle-helper claim was an interior extent.

The retry hypothesis was that current declarations and the owned module layout would remove the old stack-slot mismatch. The landed `ParticleConstructor.cpp` stores float position and emitter coordinates at +0x1C and +0x28, the byte flag at +0x38, lifetime at +0x68, and callback results at +0x8C, +0x90 and +0x94. Those writes were checked in the complete decoded constructor. This is field evidence, rather than proof that the target's owner can discard its address token.

The target's first two indirect calls are the inline expansion of the shape independently landed as `Y3Reset_005CC0B0::resetAll`. Its complete 35-byte body checks pointer fields +0 and +4, calls slot +4 on each non-null receiver, then adjusts ECX by eight and tail-jumps through ILT 0x00011013. That thunk jumps to `Y3ResetTail_005CAB40::resetAll`. The complete 68-byte tail checks pointers at +0, +4 and +0x10 and walks the pointer range at +0x14 and +0x18 with a four-byte stride. The reconstruction models the group as an embedded object at +0x8C and preserves that native inline reset. Flat fields, an inline reset on the enclosing owner, and alternative receiver spellings retained an extra EDI save and member-address commoning. The nested group removes that residue and recovers the retail local slots. Refutation would be a differing decoded receiver, field offset, stride or branch, or a failing relocation-aware byte gate on the final source.

The module dispatch view claims only the exercised call-site ABI. Slot +4 receives ECX and no stack arguments; its result is unused. Slot +0x24 receives ECX and one four-byte floating-point argument. Each complete target path restores the same stack without caller argument cleanup, so this slot cleans four bytes. There is no receiver adjustment or hidden return buffer. Neither slot supplies a consumed return value or an independently established dynamic class name. Unused vtable entries are declaration placeholders. No module value constructor, STL container identity or allocation-size inference is used by this recovery.

The saved source's `acosf` spelling expands to a CRT intrinsic under its flags. Retail instead calls the ten-byte `ACos(float)` wrapper at 0x00873940, which loads its stack argument into the x87 stack, calls the six-byte `_CIacos` import stub at 0x009F7256, and returns the x87 result without popping its caller's argument. The import stub jumps through the msvcr71.dll `_CIacos` IAT cell at VA 0x01359230. The final declaration uses the existing canonical `ACos` identity. No new pin is needed.

`Particle::isInvisible` is declared with its canonical boolean return. Its complete 91-byte instruction body returns through AL and is followed by its switch tables, bringing the ledger extent to 107 bytes. The strict linear extent checker rejects the full extent because it ends inside a fictitious instruction decoded from table data. The code-only check succeeds; the two table destinations are VA 0x009C31CF and VA 0x009C31E1, with the seven-byte selector map checked separately. The target's lifetime-expiry path clears AL, and its visibility path negates the returned AL before materializing the boolean. The saved integer-return declarations were not retained.

Raw decoded bodies, boundary bytes, checked-callee outputs, every trial source, the finite family search and unedited probe outputs are retained under `build/retry-005cc6c0/`. `18_native_group.cpp` was the first masked exact experiment. The source was then independently probed at its final path, `game/GameEngine/Source/GameClient/System/Rva005CC6C0ParticleUpdate.cpp`. The scoped gate and declaration checks are separate from the masked probe. No shared header, STL pin, policy or tooling file is changed.

The relocation-aware scoped gate passes at the final source path, as do the declaration, canonical-class, name-preservation and pin-consistency checks.
