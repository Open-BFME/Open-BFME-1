## Measured hypothesis and refutation

The bank explicitly manipulated a flag word and cached one final status pointer. It also used an `if` statement around filename construction. These forms omitted static-initialization rollback, conditional full-expression destruction and fresh reads of each cached Image after status mutation. The new hypothesis was that native function-local statics and one short-circuit expression would recover the frame and unwind states, while separate branch tests would recover the remaining control flow. An unchanged frame, cleanup map or byte score would refute the hypothesis.

The old bank emits 499 bytes with 337 differing bytes in the overlap and 92 missing retail bytes. Native statics alone emit 513 bytes with 330 overlap differences. Adding the short-circuit expression emits 564 bytes with 286 overlap differences and recovers the twelve-byte frame and EH prologue. Restoring separate null-map and fallback-image tests emits all 591 bytes exactly. Generated EH flag and exception-specification variants did not improve the old bank. Inline API forwarding wrappers were also rejected because they changed scheduling and emitted 592 bytes; canonical calls and typed references to actual thunks restore the exact result.

Reopening or rejecting the recovery is justified by a decoded caller passing a different receiver or argument, a different filename-field representation, a cleanup action targeting another destructor, or any failure of relocation-aware byte verification.
