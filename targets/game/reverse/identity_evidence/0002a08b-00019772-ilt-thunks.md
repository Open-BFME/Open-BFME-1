# ILT thunks 0x0002A08B and 0x00019772 are claimed by address

Both 5-byte rows named a function the thunk does not reach. TU-local shim pins made
the tail jumps resolve.

| Old name | Thunk | Jumps to | What the target is |
|---|---|---|---|
| `??1LogicalDecalClass@MultiFixedPoolDecalSystemClass@@QAE@XZ` | 0x0002A08B | 0x005D7520 | the destructor matched as `??1HemisphericalEmissionVelocityModuleTemplate` |
| `?buildFieldParse@ActiveBodyModuleData@@SAXAAVMultiIniFieldParse@@@Z` | 0x00019772 | 0x002284A0 | OpenContain's module-data field-parse builder |

## 0x0002A08B

Retail calls 0x0002A08B only from `??_GHemisphericalEmissionVelocityModuleTemplate`
(0x005D75D0) and `??_EHemisphericalEmissionVelocityModuleTemplate` (0x005D7600). The
latter also pushes it as its element destructor. Both matched rows name it
Hemispherical's destructor. No LogicalDecalClass code reaches it. The one row that
used the LogicalDecalClass name for a destructor ILT was the vector deleting
destructor at 0x005D7480, and that row is SphericalEmissionVelocityModuleTemplate's
(005d7480-spherical-emission-velocity-template-vector-dtor.md).

## 0x00019772

ModuleFactory::init pushes the string "OpenContain" (0x01090BA4) at 0x0012CB42. It
then stores createProc ILT 0x0001E51F (-> 0x00115960, `friend_newModuleInstance@OpenContain`)
and createDataProc ILT 0x00002B30 (-> 0x001159E0, `friend_newModuleData@OpenContain`).
That factory passes 0x00019772 to `INI::initFromINIMultiProc`. The body 0x002284A0 adds
a table that starts with ContainMax and then `DieMuxData::getFieldParse()` at offset
8. That is ZH's OpenContainModuleData::buildFieldParse shape.

The "ActiveBody" registration (0x0012FE28) stores factory 0x0011F420, and that factory
passes ILT 0x00012355, not 0x00019772. Retail's callers of 0x00019772 are six builders
of OpenContain-derived module data: 0x00115A80, 0x00116500, GarrisonContainModuleData
0x00125440, 0x00220160, 0x0022DB70 and 0x00248F00.

Both rows are now the address-claimed ILT thunks `?j_0002a08b@@YAXXZ` and
`?j_00019772@@YAXXZ`. They tail-jump to `?b_005d7520@@YAXXZ` and `?b_002284a0@@YAXXZ`,
pinned at the bodies. The two shim sources and their shim pins are deleted.
