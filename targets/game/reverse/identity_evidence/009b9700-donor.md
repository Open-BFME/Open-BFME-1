The tested base is `2e661a49fb01f4664b324ceff8df105f6da85c5c`. The source preserves the bank's `_Rva009B9700Vp6Reconstruct` identity and `Rva009B9700Vp6Context` names. The owner remains unknown. The Open BFME 2 donor is `Code/GameEngine/Source/Common/Rva001CA000Vp6WideAccum.cpp`, `_Rva001CA000Vp6WideAccum` at game.dat RVA 0x001CA000. The caller does not consume a return value, and this target has no defined output in a return register; all results are memory writes.
