# RVA 0x0081D8F0: address-owned initialization wrapper

The preceding retail routine returns with RET 4 at 0x0081D8ED, ending at
0x0081D8EF. This wrapper starts at 0x0081D8F0, returns with RET 4 at
0x0081D912, and is followed by INT3 padding from 0x0081D915. Its extent is
37 bytes, matching the old dump row.

The receiver arrives in ECX with one stack argument. The body clears receiver
+0 and +4, passes that argument and zero to 0x0081D5E0 with receiver +8,
then returns the original receiver in EAX. These operations match the existing
address-owned wrapper at 0x0081C860, apart from the one call displacement.
The original constructor, container, element type and allocator type remain
unproven; the reconstruction retains addresses in type and method names.

## Independently decoded callee ABI

The direct callee at 0x0081D5E0 is bounded by INT3 padding and contains:

```
mov eax, ecx
mov ecx, [esp+8]
mov [eax], ecx
ret 8
```

It ignores the first stack word, stores the second at receiver +0, returns
the receiver, and cleans two stack words. Its 11 bytes exactly match the
previously typed helper at 0x0081C6A0. A fresh isolated native C++ ABI probe
also reproduces all 11 bytes with no relocations.

The existing `dup_0081d5e0` row borrows an AudioEventInfo hashtable allocator
proxy object symbol from GameAudio.cpp. Neither that borrowed identity nor
the short store-only body proves template arguments for this wrapper.
One address-specific pin states only the observed thiscall ABI: ignored
pointer-shaped first argument, unsigned second argument, receiver result.
It targets the physical 11-byte body directly and leaves the existing helper
ledger row and GameAudio.cpp unchanged. It is an address binding, not a
claim of a newly linkable native provider.

Retail instructions and boundaries were independently checked against the
retail-1.03-unpacked image. A bounded Ghidra read-only query reproduced its
instruction bytes but found no function record for either address; no
Ghidra-derived identity or function signature is claimed.
