# `DX8Wrapper::Set_Vertex_Shader_Constant` at 0x0071BEB0

* **Pair.** 0x0071BF30, matched as `DX8Wrapper::Set_Pixel_Shader_Constant`,
  is this body instruction for instruction (same 94 bytes, same state-cache
  compare and store) except for the device call: it calls device vtable
  +0x1B4, this one +0x178. They are dx8wrapper.h's inline pair.
* **Device slot.** +0x178 is index 94 and +0x1B4 index 109 of the device
  interface BFME's wrapper holds. In IDirect3DDevice9 these are
  SetVertexShaderConstantF (94) and SetPixelShaderConstantF (109), so the body
  that calls 94 is the vertex-shader half of the pair.
* The dxwrapper.cpp C++ has always compiled under this symbol (the row's
  object-symbol note); only the ledger row carried the `?d_` placeholder.
