# Bank identifiers at 0x00925D10 (bfmeSet1016)

The caller 0x0092C350 pushes three arguments and the body ends `ret 0xC` at
+0x65F. Nothing in the image names the buffer type the body walks or the
function at 0x009371E0 it calls. The old bank's `Bfme1016ArrayView`,
`bfmeVS01016`, `m_bfmePad00` and `m_bfmePad74` were invented temporary names
(Bfme<noun><digits> and padding spelled as if it were a witnessed field). The
rewritten bank uses address-derived names instead: `Rva00925D10Buf` for the
buffer, `rva009371E0Inc` for the callee, and plain `m_pad0`/`m_pad2` for bytes
whose meaning is unknown. No witnessed layout (reverse/bfme_layouts.json) or
field name covers these offsets.
